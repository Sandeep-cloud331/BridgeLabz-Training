# My Greetings App

Servlet & Spring MVC learning project.

## What I've learned so far

- Created a basic Java Web application using Maven.
- Configured the project as a `WAR` and deployed it manually on Apache Tomcat.
- Created and ran a basic `FirstServlet`.
- Understood how Tomcat handles HTTP requests and maps URLs to Servlets.
- Learned the structure of a Java Web Application:
  - `src/main/java`
  - `src/main/webapp`
  - `WEB-INF`
  - `META-INF`
  - `pom.xml`
  - `target`
- Created a basic predefined-user login using `LoginServlet`.
- Created `login.html` and `LoginSuccess.jsp`.
- Learned how Servlets, Tomcat, `web.xml`, and WAR deployment work together.
